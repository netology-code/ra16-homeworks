Props
====

Задачи:

1. [Список предложений](listing).
2. [История сообщений в чате](chat).

Все задачи лучше делать в разных репозиториях, то есть реализовать два проекта, чтобы не
было конфликта стилей. Но если вы позаботитесь о том, что конфликта не будет, то можете сделать и в одном проекте.

**Важно!**  
Задачи должны быть написаны на TypeScript. Все Props должны быть типизированы. Использование типа any не
допускается.
