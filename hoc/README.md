HOC — Higher Order Components
===
## Выполнив это задание, вы:

- научитесь создавать компоненты высшего порядка (HOC), которые оборачивают другие компоненты, добавляя новую функциональность;
- поймёте, как правильно передавать и модифицировать пропсы (props) через HOC, сохраняя их типизацию и избегая конфликтов;
- научитесь интегрировать HOC в существующую структуру компонентов, обеспечивая повторное использование логики;
- изучите на практике, как HOC позволяют изолировать и переиспользовать логику, упрощая поддержку и масштабирование кода;
- познакомитесь с альтернативными подходами, такими как Render Props и хуки, и сможете сравнить их с HOC.

## Описание задания

Необходимо выполнить и предоставить на проверку следующие задачи:

1. [HOC для управления темой](theme_provider).
2. [HOC для контроля доступа](authorization).
3. [HOC для отслеживания фокуса](focus_tracker) — необязательная задача.

## Инструкция к выполнению

Все три задачи лучше сдавать в разных репозиториях, то есть реализовать три проекта, чтобы не
было конфликта стилей. Используйте сборщик Vite для формирования проекта.

**Важно!**  
Все задания должны быть выполнены на JavaScript, но допускается их реализация на TypeScript. Все Props должны иметь свой тип или интерфейс. Использование типа any не допускается.

#### Способ создания приложения React с использованием тулинга Vite

Приложение также можно создать используя инструмент Vite.
Документация по созданию приложения [React](https://vitejs.dev/guide/).

1. Откройте терминал и пропишите следующую команду: `yarn create vite my-app --template react`,
   либо `yarn create vite my-app --template react-ts`, если
   нужен шаблон с TypeScript. Эта команда создаст настроенный
   шаблонный проект.
2. Откройте созданный проект в своей IDE.
3. Установите зависимости.
4. Готово. Чтобы запустить приложение, введите команду: `yarn dev`(либо `npm run dev`).
